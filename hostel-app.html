What it is

A hostel attendance system built end-to-end for the Uniworld hostels at Scaler School of Technology — a React Native app plus its own Node.js backend. The attendance window is real and server-enforced: it opens at 10:30 PM, closes at 11:00 PM, and a strict grace period ends at 11:10 PM IST. Changing your phone’s clock does nothing — the server keeps its own time.

How a check-in flows through the system

▶ Run a check-in on the phone — each stage below lights up as it happens.

  1. Liveness challenge issued

    POST /attendance/liveness-challenge — the server hands the phone a one-time task: blink once, blink twice, or turn your head left or right.

    REQUEST
  2. Live camera + ML Kit

    An in-app camera opens (no swappable camera apps), and ML Kit tracks eyes and head pose on-device while frames are captured inside the oval guide.

    ON DEVICE
  3. Face verified on the server

    POST /attendance/verify-face — duplicate frames are rejected by hash, the challenge is re-derived from the actual pixels via Face++, and the selfie is compared against the enrolled signup photo. A signed face-attestation token comes back.

    GATE 1
  4. Geofence + anti-spoof

    The GPS fix must fall inside the hostel’s mapped property boundary (with a 100 m allowance). Fake-GPS “mock location” apps are detected natively and rejected.

    GATE 2
  5. Hostel Wi-Fi challenge

    The Wi-Fi SSID must be an authorized hostel network, the device IP must sit in the router’s subnet, and the app runs a real reachability probe to the hostel gateway — a copied network name isn’t enough.

    GATE 3
  6. Server-authoritative mark

    POST /attendance/mark — the server re-checks the time window on its own clock, validates the attestation token, geofence and network again, blocks duplicates, and only then records PRESENT.

    WRITE
  7. Nightly automation at 11:10 PM

    The absentee list is computed, a Google Sheet is created for the night, the monthly register is updated, and a PDF report is generated — all waiting on the warden dashboard.

    ADMIN

The warden side

A separate web dashboard for hostel staff (no public signup — accounts are provisioned per warden): per-night present/absent counts, a Download PDF button for the absent list, View Sheet for the night’s Google Sheet, and a Monthly Register — one row per student, one column per day.
