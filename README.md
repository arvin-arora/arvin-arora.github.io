# Arvin Arora — Portfolio

My personal developer portfolio: hand-written HTML, CSS, and JavaScript — no frameworks.

**Live site:** https://arvin-arora.github.io

## Features

- Live Codeforces stats (solved count + max streak) fetched from the public API on every visit
- Animated coding terminal, typewriter headline, particle background, custom cursor
- Generative ambient music synthesized with the Web Audio API
- Fully responsive, respects `prefers-reduced-motion`
